# MATRIX CLIENT 2.0

**Matrix Client for MineFun.io**

A GitHub-hosted Tampermonkey edition of Matrix Client with the Matrix interface:
**Mods · Settings · MMMD**.

The Tampermonkey loader is intentionally small. `use.js` loads the current
runtime from the repository with `@require`, while the runtime hosts the UI,
module registry, persistent settings and Matrix-owned assets.

## Matrix profile

**alex-PRIME** is configured as a Matrix badge profile. The badge engine can
attach the Matrix badge to matching chat names when the current MineFun page
exposes compatible chat DOM nodes.

## Included module families

Zoom, Crosshair, Keystrokes, Direction HUD, Auto GG, Texture Pack, Hide Arm,
FPS, CPS, Clear Screen, Translation, K/D, Damage Vignette, Armor HUD, Block
Outline, No Fog, Hide Nametag, Hurt Cam, Toggle Crouch, Hide Particles, Hide
Clouds, BedWars Notifications, Arm Position, Scoreboard, Chat Emojis, GUI Scale,
Action Bar, Custom UI, Custom Badges, Shaders, Performance Mode, Smooth Camera,
Cinematic FX, Mouse Trail, Stopwatch, Display Enhancer, Visual Keyboard, Matrix
Hub, Dark Mode, Full Bright, Galaxy Mode, Weather FX, Screen Effects,
Flashlight, Game HUD and Font Manager.
