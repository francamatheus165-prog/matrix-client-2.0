# Matrix Client 2.0

**Matrix Client for MineFun.io**

A GitHub-hosted Tampermonkey client with the original Matrix Client interface:
**Mods · Settings · MMMD**, search, configurable module options, keybinds and
persistent local settings.

The public loader is `use.js`. The full runtime is loaded with `@require`
from the Matrix GitHub repository.

The interface is Matrix-owned. It does not use the Celestar menu layout.
